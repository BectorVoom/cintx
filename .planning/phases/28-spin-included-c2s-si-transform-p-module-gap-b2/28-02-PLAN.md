Implement a generic, reusable `#[cube]` σ·p G-tensor assembler. It computes `g1 = nabla_i(g0)`
using the existing nabla recurrence (faithful CINTnabla1i_1e, one_electron.rs:~7753):
  ai2 = -2.0 * ai;
  g1[off] (ix==0)   = ai2 * g[off+1];
  g1[off+ix] (ix>=1)= (ix as f64) * g[off+ix-1] + ai2 * g[off+ix+1];
then forms the 3 Pauli components per cart n (one_electron.rs:~7722, the gradient s[0..2] mix):
  s[0] = g1x * g0y * g0z;   // → gc_x
  s[1] = g0x * g1y * g0z;   // → gc_y
  s[2] = g0x * g0y * g1z;   // → gc_z

For int1e_sp (tensor_rank=1) the 4-component gout per cart is [s0, s1, s2, 0] with the SCALAR slot
(gc_1) = 0.0 (intor3.c:431-434, Spike Target E):
  gout slot 3 (gc_1) = 0.0   // int1e_sp scalar slot is ZERO

OUTPUT LAYOUT (Spike Target C / Shared Pattern gout→gc): emit PRE-BLOCKED component-leading —
`gc[comp*(nf*ictr*jctr) + n]` — following `write_component_leading_staging` (one_electron.rs:~8300),
so the host transform reads gc_x=block0, gc_y=block1, gc_z=block2, gc_1=block3 in order. Do NOT emit
the interleaved `gout[n*4+comp]` layout to the consumer; the host then needs no separate transpose.
(libcint hides this transpose in CINTdmat_transpose, cint1e.c:157; emitting pre-blocked on-device is
the recommended cintx equivalent.)

D-03 REUSABILITY: parameterize the assembler by `(tensor_rank, which-slot-is-nonzero)` so
int1e_sigma (tensor_rank=3, 12-component, gout[n*12+...]) and Phase-29 families emit through the same
gc-block packing. For int1e_sp: tensor_rank=1, Pauli in x/y/z, scalar slot=0. Use comptime parameters
for tensor_rank where CubeCL requires it (follow the comptime-nroots template in
project_first_gpu_family_2c2e). Internal f64, F-output (per the 2c2e template).

CubeCL constraints: no plain-fn calls inside #[cube] (inline or use #[cube] helpers), no if-expr
(use statement-form), F::exp/F::sqrt for math, u32/i32 loop counters with `as usize` at index sites,
no continue/break. Provide a `*_host()` pure-Rust wrapper replicating the kernel logic for the
device-vs-host test (established pattern, project memory reference_cubecl_authoring_manuals /
host-wrapper pattern).

Add the device-vs-host + s×s sanity + layout tests from <behavior>. If a ~1e-11 drift appears,
