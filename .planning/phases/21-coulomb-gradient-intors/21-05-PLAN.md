Purpose: `int2e_ip1` is the two-electron force — the single highest-impact term in HF/DFT/MP2/CCSD analytical gradients. The first-derivative math already exists: `gout_ip1` + `nabla1i_2e` in f12.rs:590-785 contain ZERO F12 logic (they implement the standard libcint `∂/∂A χ_l = -2α·χ_{l+1} + l·χ_{l-1}` / `CINTnabla1i_2e`). The G-tensor must be built with `li_ceil = li+1` headroom (f12.rs:1163-1168 shows `build_f12_shape(li_ceil, ...)` then `gout_ip1(g, &shape, li, ...)` at BASE li — the same recipe). The component-leading F-order is Risk R3: pyscf-gto declares `[3, …]` component-leading F-order; the kernel staging must match exactly or pyscf-rs repacks wrong.
