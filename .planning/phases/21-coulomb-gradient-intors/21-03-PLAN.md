<objective>
Implement the `int1e_ipovlp` (overlap-derivative / Pulay) and `int1e_ipkin` (kinetic-derivative) 3-component gradient kernels by extending the existing 1e dispatcher with `ipovlp`/`ipkin` operator-symbol branches, applying the bra-center nabla (`∂/∂Ai`) to the overlap/kinetic G-tensors, and add byte-identity oracle parity tests vs vendored libcint 6.1.3 at atol=1e-12 on H2O/STO-3G.

Purpose: `int1e_ipovlp` is the Pulay/overlap-derivative term and `int1e_ipkin` is the core-Hamiltonian kinetic-derivative term — both are needed by every HF/DFT analytical gradient. They are the lowest-risk gradient families (no Rys roots, no rinv origin, no atom loop): pure Obara-Saika nabla on G-tensors already built by the base overlap/kinetic kernels. The nabla identity `∂/∂A χ_l = -2α·χ_{l+1} + l·χ_{l-1}` is the standard libcint `CINTnabla1i_1e`; the existing `contract_kinetic` (one_electron.rs:208) already applies the sibling `CINTnabla1j_1e` (ket derivative) for kinetic energy, so the bra-derivative pattern is a direct mirror.

Output: `ipovlp`/`ipkin` branches in the 1e dispatcher (one_electron.rs:486-495 extension); `vendor_int1e_ipovlp_{cart,sph}` + `vendor_int1e_ipkin_{cart,sph}` FFI wrappers; `one_electron_grad_parity.rs` with 4 byte-identity tests (ipovlp cart/sph, ipkin cart/sph).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| planner-allocated staging buffer ↔ kernel write | The kernel must write exactly 3 × ni × nj elements; a mis-sized write past the auto-allocated 3-component buffer is a memory-safety fault, not an attacker surface. |
| shell angular momenta ↔ G-tensor headroom | li raised to li+1 by the nabla; if the G-tensor isn't allocated with the extra headroom, the nabla reads out of bounds. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

Determinism/component-count unit tests exercise s/p shells where the boundary is hit. |
