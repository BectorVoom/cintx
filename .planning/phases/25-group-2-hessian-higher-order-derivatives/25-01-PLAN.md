<objective>
Implement the Rys `nroots>=6` host-side root/weight engine (FND-02) so high-angular-momentum
shells reach byte-identity and no family returns `UnsupportedApi` purely because `nroots>5`.
Port libcint 6.1.3's n>5 path **verbatim** host-side per D-01 (Flocke modified-moments ->
Wheeler recursion -> vendored MRRR tridiagonal eigensolve -> root transform), extend the
executor l-gate (D-02), and validate on a dedicated nroots 6..12 vendor sweep (D-02/D-03).

Purpose: FND-02 is the gating long-pole. Every HESS family that rides the nuclear/Rys path
(HESS-01 nuc/rinv, the entire 2e Hessian set) can elevate to nroots 6 on Hessian-elevated
d-shells; without this, those families would falsely report `UnsupportedApi`. The single
highest-risk piece is porting `eigh.c`'s `#else` vendored MRRR (~1400 lines) — it is split out
into its own task (1a) ahead of the Wheeler/Jacobi machinery (1b) that feeds it.

Output: Host Wheeler engine + MRRR eigensolver + executor gate extension + launcher host-routing
for nroots>=6 + a vendor nroots-sweep parity test + xtask table-blob drift-gate.

Wheeler partial core (rys_wheeler.c:3441-3477):
```c
wheeler_recursion(n, alpha, beta, moments, a, b);     // moments -> tridiagonal (a,b)
for (i=1;i<n;i++) b[i] = sqrt(b[i]);                  // off-diag = sqrt(beta)
_CINTdiagonalize(n, a, b+1, roots, c0);               // eigh.c #else MRRR
for (i=0;i<n;i++) {
    roots[i]   = roots[i] / (1 - roots[i]);
    weights[i] = c0[i*n]*c0[i*n] * mu0;
}
```

Eigensolver: cintx oracle build does NOT define LAPACK_FOUND, so the vendor reference uses
eigh.c's #else vendored MRRR (`_dlarrk`,`_dlasq2/4/5`,`_compute_eigenvalues`,`_dlarrf`,`_dlaneg`).
This is ~1400 lines of LAPACK-3.9.0-derived numerics — RESEARCH names it the single highest-risk
FND-02 piece. Port THIS, not a Rust LAPACK binding (last-ULP divergence breaks atol=1e-12).
See Don't Hand-Roll.

Long-double caveat: HAVE_SQRTL/HAVE_QUADMATH_H disabled (build.rs:169,171). "long double"
ops in the lrys path are f64 + c99_sqrtl (Babylonian one-step refinement, rys_roots.c:1776)
and c99_expl (= exp, :1792). Replicate these exactly for nroots>=8; do NOT use Rust extended precision.

Executor gate (executor.rs:135-142): the `ang_momentum>4 -> validated_4c1e_error("max(l)>4")`
gate is the Validated4C1E validator, NOT the global nroots gate. The real nroots ceilings are

route nroots 6..12 to the host fill_g_tensor_2e path; (c) extend the 4c1e l-gate to the validated l.
