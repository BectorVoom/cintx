### FND-03 manifest `complex_output` flag — the full codegen chain

The flag must be threaded through FOUR linked sites so `cargo build -p cintx-ops`
regenerates `api_manifest.{rs,csv}` and `manifest-audit` auto-syncs (D-10). Recommended
shape: **`complex_output: bool`** (mirrors `component_rank` exactly).

**(a) Lock JSON entry — add `complex_output` to the entry schema.**
`crates/cintx-ops/generated/compiled_manifest.lock.json` — current entry shape (NO
`component_rank`/`complex_output` keys today; those default in build.rs):
```json
{
 "id": { "family": "1e", "operator": "overlap", "representation": "cart",
         "symbol": "int1e_ovlp_cart" },
 "oracle_covered": true,
 "profiles": ["base","with-f12","with-4c1e","with-f12+with-4c1e"],
 "stability": "stable"
}
```
GIAO entries add `"id": {... "operator":"govlp", "symbol":"int1e_govlp_sph"}`,
`"component_rank": "3"` (or `"9"`), `"complex_output": true`. **Backfill
`"complex_output": true` on every existing `*_spinor` entry** (Pitfall 5) — else they
regress to real sizing when the planner SET is re-keyed.

**(b) build.rs deserialize + propagate** (`crates/cintx-ops/build.rs:335-376`).
Add `complex_output: Option<bool>` to `LockEntry` (alongside `component_rank: Option<String>` at `:341`)
and `complex_output: bool` to `GeneratedEntry` (alongside `component_rank: String` at `:365`).
The `From<&LockEntry>` impl (`:378-409`) defaults it exactly like `component_rank`:
```rust

// add:
complex_output: entry.complex_output.unwrap_or(false),
```
Then emit it in the `ManifestEntry { ... }` literal writer (near `:104` where
`component_rank: {component},` is written) and append a CSV column to the header at
`:166` and the row writer at `:178`.

**(c) ManifestEntry struct** (`crates/cintx-ops/src/resolver.rs:99-115`) — add field
mirroring `component_rank`:
```rust
pub struct ManifestEntry {

    // ...

```

**(d) Generated literal** (`crates/cintx-ops/src/generated/api_manifest.rs`) — regenerated;

### `crates/cintx-rs/src/api.rs` — `complex_values()` view (D-03, NO change)

```rust
pub fn complex_values(&self) -> Option<Vec<num_complex::Complex<F>>> {
```

(`plan.operator_env_params.common_orig.unwrap_or([0.0;3])`); raw slot `PTR_COMMON_ORIG`

```rust
if plan.representation == Representation::Spinor {
    return Err(cintxRsError::UnsupportedApi { requested: format!("spinor int1e_{op_name} moment") });
```

**Source:** `tests/moment_r_parity.rs:15,20-21` + `moment_common.rs:38-39` (ATOL=1e-12, RTOL=0).

parity silently skips (project memory).

**Source:** RESEARCH §"gout Component-Index Order" (intor1.c/intor2.c/intor3.c/intor4.c:1255).
**Apply to:** every kernel's gout transcription — the `c[]·s[]` linear combos are not
derivable by inspection; transcribe exactly, gate with the non-square block (D-12/D-13).
