## Accomplishments

- `AoSymmetry` enum with `#[default]` on `S1`, `#[repr(u8)]`, lowercase pyscf `Display` (`s1`, `s2ij`, `s2kl`, `s4`, `s8`); re-exported through `cintx-core::lib` and `cintx-rs::prelude`.

- OperatorId shift +2 propagated to all three hard-coded constants in `crates/cintx-rs/src/api.rs`:
  - `INT4C1E_CART_OPERATOR_ID` 22 → 24
  - `INT2E_STG_SPH_OPERATOR_ID` 100 → 102

- Two new vendor FFI wrappers added: `vendor_int3c1e_p2_sph` (R4 sph sibling) and `vendor_int3c2e_cart` (R1 promotion). Both mirror the existing arity-3 wrapper shape exactly.
- `crates/cintx-oracle/build.rs` updated: supplemental header gained `int3c1e_p2_sph` and `int3c2e_cart` declarations; bindgen allowlist regex was extended to expose the matching `ffi::*` bindings.
- `vendor_int3c2e_ip1_sph` deliberately NOT added (Plan 18-03 reuses `vendor_int3c2e_sph` per RESEARCH A6 / Item 5).

- **Fix:** Applied the same `"int3c2e" => None` arm and `let Some(kind) = macro_kind(&base_symbol) else { continue };` early-continue pattern to the duplicate in `crates/cintx-ops/src/lib.rs`.

- **Committed in:** `f601635` (Task 2 commit).

**2. [Rule 1 - Bug] Propagated OperatorId +2 shift to two additional hard-coded constants beyond `INT4C1E_CART_OPERATOR_ID`**
- **Found during:** Task 2, while scanning `crates/cintx-rs/src/api.rs:495-505` per PATTERNS.md §Step 2 mandate.
- **Issue:** PATTERNS.md §Step 2 listed only `INT4C1E_CART_OPERATOR_ID: u32 = 22 → 24`. After the manifest insertion at indices 22/23, the regenerated `MANIFEST_ENTRIES` showed `int2e_stg_sph` shifted from 100 to 102 and `int2e_ipip1_sph` shifted from 110 to 112 — both referenced by hard-coded constants `INT2E_STG_SPH_OPERATOR_ID = 100` and `INT2E_IPIP1_SPH_OPERATOR_ID = 110` in api.rs. Without updating, the `with-f12` and `not(unstable-source-api)` test gates would silently point to the wrong operator.
- **Fix:** Updated both constants to 102 and 112 respectively in the same Task 2 commit.
- **Files modified:** `crates/cintx-rs/src/api.rs`
- **Verification:** `cargo build --workspace --locked` passes; per-package tests pass under default features.
- **Committed in:** `f601635` (Task 2 commit).

**3. [Rule 3 - Blocking] Added `int3c1e_p2_sph` and `int3c2e_cart` to bindgen allowlist + supplemental header in `crates/cintx-oracle/build.rs`**
- **Found during:** Task 3, when `CINTX_ORACLE_BUILD_VENDOR=1 cargo build -p cintx-oracle --features cpu --locked --tests` failed with `E0425: cannot find function int3c2e_cart in module ffi` and `E0425: cannot find function int3c1e_p2_sph in module ffi`.

- **Committed in:** `3bca291` (Task 3 commit).
