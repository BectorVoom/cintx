# Quick Task 260530-j62: Fix CR-01 — unreachable unstable-source profile-membership check

## Self-Check: PASSED

## What shipped
`crates/cintx-compat/src/raw.rs` `validate_profile_and_source_gate` collapsed from two
`is_source_only()` blocks (the first returning `Ok(())` early, making the second's membership
check dead code) to a single reachable block. CR-01 closed: a source-only operator compiled into
no available profile is now rejected with `UnsupportedApi` instead of silently accepted.

## Key design decision (why NOT the review's literal suggestion)
The code review suggested folding in the dead block's `is_compiled_in_profile("unstable-source")`
check. That is WRONG and would regress two entries. `active_manifest_profile()` only ever returns
`base`/`with-f12`/`with-4c1e`/`with-f12+with-4c1e` — never `"unstable-source"`. The manifest has
two source-only `unstable::source::2e` symbols compiled in the BASE profiles, alongside
origi/grids/breit/origk/ssc in `unstable-source`. The correct rule: after the feature gate, accept
iff the symbol is compiled in the **active profile OR `unstable-source`**; reject when in neither.
