- `#[cube]` `cint_diagonalize` (eigh) running on `CpuRuntime`.
- `#[cube]` Wheeler engine for nroots 6/7 (pure f64).
- `#[cube]` Wheeler engine for nroots 8..12 (double-double) — OR a documented, parity-honest escape hatch keeping that band host-side if the CubeCL CPU backend cannot fuse FMA faithfully.
- A new in-crate nroots-6..12 reference-table test (gold values from the libcint vendor harness; documented parity split — atol=1e-12 for 6/7, max(atol=1e-12, rtol=1e-9*|ref|) for 8..12) that catches double-double regressions without a vendor build.
