# Quick Task 260529-e69 Summary: `center_3c1e` CubeCL device kernel + ROCm random oracle test

Ported `center_3c1e` from a host-only f64 pipeline to a real CubeCL
`#[cube(launch)]` device kernel generic over `F: Float` (f64 device compute,
F-cast output), routed through the resolved backend's `ComputeClient`, and added
a deterministic random ROCm `int3c1e_sph` idempotency oracle test. All four
verification gates pass; the ROCm *device* run is deferred to the orchestrator.

## Files changed

### `crates/cintx-cubecl/src/kernels/center_3c1e.rs` (rewritten)
- **`center_3c1e_kernel<F: Float + CubeElement>`** — new `#[cube(launch)]` device
  kernel. Single work item (`UNIT_POS == 0`). Inlines the entire G-tensor fill
  (base case → combined-(j+k) VRR with NEGATIVE-sign `disp = -rjrijk` → i-HRR →
  k-separation HRR) and the triple Cartesian contraction (i fastest, k slowest:
  `cart_out[(k_idx*ncj + j_idx)*nci + ci_idx]`). Obeys the authoring checklist:
  `F::exp`/`F::sqrt`/`F::cast_from`/`F::new` (no methods), statement-form `if` for
  per-axis displacement selection, `u32`/`i32` indices, `while` loops with manual
  counters, exponent screen guarded with `if eijk <= expcutoff { .. }` (no
  `continue`; counter always advances), one `#[cube(launch)]` entry, li/lj/lk and
  nprim*/nctr* as runtime `u32` args (no `#[comptime]`). Per-primitive coefficient
  product `ci*cj*ck` folded into `fac` inside the primitive loop.
- **`run_3c1e_device<R: Runtime>`** — new generic-over-Runtime dispatcher; f64
  buffers via `client.create_from_slice(f64::as_bytes(..))`, launch
  `center_3c1e_kernel::launch::<f64, R>(.., CubeCount::Static(1,1,1),
  CubeDim::new_1d(1), ..)`, read back via `client.read_one_unchecked`.
- **`launch_center_3c1e_typed::<F: CintFloat>`** — numeric core now routes through
  `run_3c1e_device::<R>` on the `match backend { Cpu | Wgpu | Cuda | Rocm | Metal }`
  arms (each `#[cfg(feature=...)]`-gated; rocm → `cubecl_hip::HipRuntime`). One
  launch per `(ck,cj,ci)` contraction triple (single launch for the nctr==1 case).
  Kept the `Representation::Spheric` (`cart_to_sph_3c1e`) / Cartesian copy tails,
  the WR-06 precision-aware nonzero sentinel, and the `ExecutionStats {..}` return
  verbatim. Signature unchanged.
- **`launch_center_3c1e`** — outer precision dispatcher unchanged byte-for-byte.
- **`fill_g_tensor_3c1e`, `contract_3c1e_ovlp`, `cart_comps`** — retained under
  `#[cfg(test)]` as the host cross-check reference.
- **tests** — added `host_cart_3c1e` host reference, `assert_device_matches_host`,
  device-vs-host cross-checks `test_device_kernel_matches_host_{sss,ssp,pss,spp,psp}`,
  the `test_center_3c1e_kernel_generic_f32` genericity launch test, and retained
  `test_center_3c1e_parity_f64`, `test_center_3c1e_f32_smoke`,
  `test_fill_g_tensor_3c1e_sss`, `test_contract_3c1e_ovlp_sss`.

### `crates/cintx-oracle/tests/center_3c1e_parity.rs` (appended)
- **`Lcg`** (rocm-gated) — deterministic LCG rng (copied from the 2c2e sibling).
- **`build_random_3shell`** (rocm-gated) — lays out 3 shells on 3 distinct atoms,
  random `li,lj,lk ∈ {0,1,2}`, nprim ∈ {1..3}, random exps/coeffs/coords using the

  .., &shls=[0,1,2], ..)` twice/case, idempotency at `atol=1e-12 / rtol=1e-10`,
  requires `any_nonzero` across the suite.
- Import: `PTR_ENV_START` added rocm-gated (keeps cpu-only build warning-free).

## Deviations from Plan

### Auto-fixed / design clarifications
1. **[Rule 3 - blocking] cpu-only unused-import warning** — `PTR_ENV_START` is only
   referenced by the rocm-gated `build_random_3shell`, so an unconditional import
   produced an unused-import warning under cpu-only. Gated the import
   `#[cfg(feature = "rocm")]` to keep the cpu build warning-free.
2. **Contraction-coefficient handling** — the device kernel folds the per-primitive
   `ci*cj*ck` coefficient product into `fac` and runs the full primitive loop per
   `(ck,cj,ci)` contraction triple (one launch for the common nctr==1 case). This
   matches the host reference's accumulation and keeps the kernel a single
   `#[cube(launch)]` entry, rather than launching once per primitive.
