contraction splice (`contract_f12_cart`, the base-variant analog of the ECP angular

center_4c1e, ECP Type-1, ECP Type-2).

family's bounded compute to a real on-device CubeCL kernel WITHOUT breaking

`crates/cintx-cubecl/src/kernels/ecp.rs`:

1. `#[cube(launch)] fn ecp_angular_kernel<F: Float + CubeElement>(...)` — single work
   item (`if UNIT_POS == 0u32`), all math in `F` arithmetic, statement-form `if`,
   `u32` indices, `while` loops bounded by runtime u32, NO break/continue, NO special
   functions, NO device-local `Array` scratch (inline-recompute). The nested loop
   order is IDENTICAL to the host driver to preserve f64 summation order.
2. `fn run_ecp_angular_device<R: Runtime>(client: &ComputeClient<R>, ...)` — creates
   device buffers via `client.create_from_slice(f64::as_bytes(..))`, launches with
   `ecp_angular_kernel::launch::<f64, R>(client, CubeCount::Static(1,1,1),
   CubeDim::new_1d(1), unsafe { ArrayArg::from_raw_parts(handle, len) }, ..., scalars)`,
   reads back via `client.read_one_unchecked(out_h)` + `f64::from_bytes`.
3. `fn run_ecp_angular_splice_on_backend(backend: &ResolvedBackend, ...)` — a
   per-backend `match` with `#[cfg(feature = "...")]` arms mapping
   `ResolvedBackend::Cpu(c) => run_..._device::<cubecl::cpu::CpuRuntime>(c, ..)`,
   `Rocm(c) => ::<cubecl_hip::HipRuntime>`, Wgpu/Cuda/Metal likewise.

Per the center_2c2e template, the kernel computes in f64 internally and is generic
over F for output. Launch at f64 here (F12 keeps f64 staging; the byte-identity gate
is f64 CPU-vs-vendor-C).

fn run_ecp_angular_device<R: Runtime>(client: &ComputeClient<R>, ...) -> Vec<f64> {
    let rad_h = client.create_from_slice(f64::as_bytes(rad_ang));
    // ...
    ecp_angular_kernel::launch::<f64, R>(
        client, CubeCount::Static(1,1,1), CubeDim::new_1d(1),
        unsafe { ArrayArg::from_raw_parts(rad_h, rad_ang.len()) }, /* ... */,

}

fn contract_f12_cart(g: &[f64], shape: F12Shape, li: u8, lj: u8, lk: u8, ll: u8) -> Vec<f64> {
    let nfi = ncart(li); let nfj = ncart(lj); let nfk = ncart(lk); let nfl = ncart(ll);
    let ci_comps = cart_comps(li); /* cj/ck/cl_comps too */
    let gx_off = 0usize; let gy_off = shape.g_size; let gz_off = 2 * shape.g_size;
    let mut out = vec![0.0_f64; nfi * nfj * nfk * nfl];
    for (l_idx, &(lx,ly,lz)) in cl_comps.iter().enumerate() {
      for (k_idx, &(kx,ky,kz)) in ck_comps.iter().enumerate() {
        for (j_idx, &(jx,jy,jz)) in cj_comps.iter().enumerate() {
          for (i_idx, &(ix,iy,iz)) in ci_comps.iter().enumerate() {
            let mut sum = 0.0_f64;
            for irys in 0..shape.nroots {
              let x_idx = irys + ix*shape.di + kx*shape.dk + lx*shape.dl + jx*shape.dj;
              let y_idx = irys + iy*shape.di + ky*shape.dk + ly*shape.dl + jy*shape.dj;
              let z_idx = irys + iz*shape.di + kz*shape.dk + lz*shape.dl + jz*shape.dj;
              sum += g[gx_off + x_idx] * g[gy_off + y_idx] * g[gz_off + z_idx];
            }
            let out_idx = i_idx + j_idx*nfi + k_idx*nfi*nfj + l_idx*nfi*nfj*nfk;
            out[out_idx] = sum;
          }}}}
    out
}
